How Does it Work?

I use an OBDII to USB Adapter to connect from my vehicles CAN Network to my Windows Laptop.
Using DarthAffe's OBD2.NET (https://github.com/DarthAffe/OBD.NET)  project I created a WinForm C# project that reads my car's speed and syncronously changes the instrumentation of the generated song.
